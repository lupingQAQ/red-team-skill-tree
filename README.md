## About

A comprehensive red team skill reference covering the full offensive security stack — from anti-attribution and reconnaissance to post-exploitation, malware evasion, cloud-native attacks, and AI-powered offense. Based on a real training curriculum, updated with 2025-2026 APT techniques.

**Author:** Lu Ping (鲁平) · WeChat: `Security丨Art`
